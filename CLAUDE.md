# Hinweise für Claude Code

## Security

Halte dich bei jeder Änderung an [`SECURITY_CHECKLIST.md`](./SECURITY_CHECKLIST.md). Prüfe die relevanten Punkte vor jeder Abschlussmeldung, behebe Verstöße direkt mit und liste nicht umsetzbare Punkte unter „Offene Security-Punkte“. Schwäche nie Sicherheit ab, um ein Feature zum Laufen zu bringen.
